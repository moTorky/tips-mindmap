##### **Using ADSI Edit**
For a graphical approach:[sec-tech.org](https://sec-tech.org/mastering-dcsync-safeguard-your-active-directory-from-advanced-attacks/?utm_source=chatgpt.com)
1. Open **ADSI Edit**.
2. Connect to the **Default Naming Context**.
3. Navigate to the domain root (e.g., `DC=yourdomain,DC=com`).
4. Right-click and select **Properties**.
5. Go to the **Security** tab and click **Advanced**.
6. Review entries for permissions like **Replicating Directory Changes** and **Replicating Directory Changes All**
