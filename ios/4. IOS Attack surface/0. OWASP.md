[OWASP](https://mas.owasp.org/) :
1. MASVS: verification standard
    => **very good as a recommendation, or vuln mitigation for your pentest report**
     https://mas.owasp.org/MASVS/
	- have standard for: **STORAGE** , **CRYPTO**, **AUTH**, **NETWORK**,**PRIVACY**
2. MASWE: weakness enum
   => for every topic it have: Overview, impact, mitigations, and link for  MASTG
   https://mas.owasp.org/MASWE/
3. MASTG: testing guide 
   => a practical guideline for how test categorized vuln  
4. MAS checklist
   => contains links to the MASTG test cases for each MASVS control.
