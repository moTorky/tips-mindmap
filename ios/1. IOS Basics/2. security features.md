IOS have a hardware and software security features
#### Hardware security features
Hardware security security on the chipset such:
-  Hardware Root of Trust
	- Security begins in hardware using an **immutable Boot ROM** (burned during chip fabrication).
	- Boot ROM ensures **only Apple-trusted code** loads during startup (Secure Boot).
- Secure Enclave
	- Dedicated silicon within the SoC for:
	    - Key generation, storage, and management.
	    - Processing biometric authentication (Face ID, Touch ID, Optic ID).
	    - Running its own **boot process** and OS, isolated from the main OS.
	- **Communication channel** ensures key material is **never exposed to the CPU or OS**.
-  File Encryption
	- File contents are **automatically encrypted** using the **AES engine**.
	- Encryption happens **in-line** during file read/write, using keys provided by the Secure Enclave.
-  **Data Protection Classes** (iOS File Encryption Model)
	- Define **when and how** data is accessible:
	
|Class|Description|
|---|---|
|**NSFileProtectionComplete**|Data is accessible **only when device is unlocked**. Strongest protection.|
|**NSFileProtectionCompleteUntilFirstUserAuthentication**|Data is available after first unlock until shutdown.|
|**NSFileProtectionCompleteUnlessOpen**|File stays accessible while open, even if device locks.|
|**NSFileProtectionNone**|No protection – data always accessible (least secure).|
#### Software security features
- App Sandbox
	- Each app runs in a **restricted container**:
	    - No access to other apps’ data or system files.
		    - `# /private/var/mobile/Containers/Bundle/Application/` holds the Application folder
	    - Limits access to hardware and OS services (unless explicitly granted).
	- Apps must declare permissions for camera, location, contacts, etc.
	- https://theapplewiki.com/wiki/Filesystem:/private/var/mobile/Containers/Bundle/Application
- System Integrity Protection
	- **Code Signing**: All executables must be signed by Apple or an authorized developer.
	- Prevents execution of unverified or modified code.
- System Updates
	- Apple delivers **timely and full-device security updates** across its device lineup.
	- All devices receive the **same build** to avoid fragmentation and missed patches.
	- for a critical vuln apple can **enforce updates**
- Secure Boot Chain
	- Ensures **only trusted Apple-signed software** runs at each stage of boot (Boot ROM → LLB → iBoot → kernel).
	- Every stage verifies the signature of the next, preventing tampering.
