### app structure on ios
_can't accessed if not jailbreak_
every app have it own sandbox; that have :
1. Bundle container -> above image: application files, images, executable, ...
	saved under `private/var/containers/Bundle/Application/GUID/` 
2. ***Data container:*** stores application data, such cashing, files 
	saved under `private/var/mobile/containers/Data/Application/GUID/` 
	1. Documents
	2. library
	3. Temp
3. iCloud container
