the application needs to be signed by the developer and signed by apple itself in order to be available in the store
the coding is done using XCODE program and the certificate of signing is called ipa
any application without signing will not run on iOS, this is only possible while connecting the mobile and building the application directly on it


Certificates of iOS
--------------------
Free Certificate >> 3 apps for 7 days and the application can be installed only at maximum on 100 device, the application can't be uploaded on the App Store
Developer Certifcate >> Certificate valid for 1 year, unlimited Apps and the application can be installed only at maximum on 100 device
		     >> Can be uploaded to the Store but still has the limited number of users, the number will be unlimited after Apple Sign it
Enterprise Certificate >> Certificate valid for 1 year, unlimited Apps,, more than 100 device
